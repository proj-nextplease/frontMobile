# Giấy phép font

Cả hai font đều theo **SIL Open Font License 1.1**, cho phép dùng trong sản
phẩm thương mại và nhúng vào ứng dụng.

- **Be Vietnam Pro** — © 2021 The Be Vietnam Pro Project Authors
  https://github.com/bettergui/BeVietnamPro
- **Archivo** — © The Archivo Project Authors
  https://github.com/Omnibus-Type/Archivo

Toàn văn giấy phép: https://scripts.sil.org/OFL

Vì sao commit file font vào repo thay vì tải lúc build: build Flutter phải
chạy được khi không có mạng, và ghim đúng phiên bản font thì giao diện không
tự đổi khi Google Fonts cập nhật.
